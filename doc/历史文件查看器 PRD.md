# 历史文件查看器 PRD 文档

**产品名称**：历史文件查看器

**版本**：v1.0

**编制日期**：2026-03-24

---

## 1. 产品概述

### 1.1 功能定位

在侧边栏提供入口，展示用户在各历史对话中生成的文件列表，支持 Markdown 文件内容预览。

### 1.2 核心功能

| 功能 | 描述 |
|------|------|
| **文件列表** | 展示跨会话的历史文件，支持搜索和筛选 |
| **文件预览** | 在侧边栏展开预览 Markdown 内容 |
| **文件下载** | 支持下载文件到本地 |

---

## 2. 功能需求

### 2.1 入口与布局

- **入口位置**：侧边栏，放在「智能体编排」下方
- **入口样式**：图标 + 文字「历史文件」
- **侧边栏展开**：点击后在右侧展开文件列表面板

### 2.2 文件列表

#### 2.2.1 列表展示

- 文件名（带文件图标）
- 生成时间
- 所属会话名称
- 文件大小

#### 2.2.2 搜索与筛选

- 搜索：按文件名搜索
- 筛选：按文件类型筛选（Markdown / 其他）

#### 2.2.3 排序

- 默认按生成时间倒序（最新的在前）
- 支持按文件名字母排序

### 2.3 文件预览

#### 2.3.1 预览面板

- 位置：右侧展开的侧边栏
- 宽度：可拖拽调整
- 内容：Markdown 渲染

#### 2.3.2 预览操作

- 滚动浏览
- 复制内容
- 下载当前文件

### 2.4 数据模型

```typescript
interface GeneratedFile {
  id: string;
  name: string;
  type: 'markdown' | 'other';
  content: string;
  size: number;
  sessionId: string;
  sessionName: string;
  createdAt: string;
  createdBy: string;
}
```

## 3. 交互设计

### 3.1 入口流程

```
用户点击侧边栏「历史文件」
    ↓
展开文件列表侧边栏
    ↓
显示文件列表（默认显示所有文件）
    ↓
用户可搜索/筛选文件
    ↓
点击文件 → 右侧展开预览面板
```

### 3.2 界面结构

```
┌──────────────────────────────────────────┐
│  历史文件                           [X]  │
├──────────────────────────────────────────┤
│  [搜索框...]              [Markdown ▼]  │
├──────────────────────────────────────────┤
│  文件列表                                │
│  ┌────────────────────────────────────┐ │
│  │ 📄 文件名.md          10:30        │ │
│  │    来自：会话名称      2KB         │ │
│  └────────────────────────────────────┘ │
│  ┌────────────────────────────────────┐ │
│  │ 📄 另一个文件.md       昨天        │ │
│  │    来自：另一个会话    5KB         │ │
│  └────────────────────────────────────┘ │
└──────────────────────────────────────────┘

预览面板（可选展开）:
┌──────────────────────────────────────────┐
│  📄 文件名.md           [下载] [复制]   │
│  ────────────────────────────────────── │
│  # Markdown 内容...                       │
│                                          │
└──────────────────────────────────────────┘
```
